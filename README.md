# 🌿 Paradise Nursery Shopping Cart Application

## 🧩 Overview
Paradise Nursery is a React‑based e‑commerce web application designed to simulate an online plant shop experience.  
It allows users to browse plant products, view details, add items to a shopping cart, and manage purchases dynamically using React and Redux.

---

## 🚀 Features
- **Product Listing:** Displays plants with images, names, descriptions, and prices.  
- **Shopping Cart:** Add, remove, and update quantities of selected items.  
- **Dynamic Total Calculation:** Automatically updates total cost as items change.  
- **Navigation:** Includes Home, Products, and Cart pages for smooth user flow.  
- **Redux Integration:** Manages global cart state efficiently.  
- **Responsive Design:** Styled with CSS for a clean, user‑friendly interface.
